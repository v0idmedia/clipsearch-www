# CLIP Search — PHP-лендинг

Самодостаточная версия лендинга без Node.js, React и OpenAI Sites. Для работы нужен PHP 7.1 или новее.

## Локальный запуск в Windows

Запустите `start-local.bat` двойным кликом. Сайт откроется по адресу `http://127.0.0.1:8080`.

Чтобы остановить сайт, закройте окно `CLIP Search PHP Server`.

## Docker / Portainer

1. Загрузите папку проекта на сервер или подключите Git-репозиторий в Portainer.
2. Создайте Stack из файла `docker-compose.yml`.
3. При необходимости замените внешний порт `8080` на нужный.
4. Создайте бота через BotFather, добавьте его в нужный чат и задайте в Stack переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
5. Создайте невидимый виджет Turnstile для домена `clipsearch.ru` в Cloudflare и задайте в Stack переменные `TURNSTILE_SITE_KEY` и `TURNSTILE_SECRET_KEY`.

Токены Telegram и Turnstile нельзя добавлять в публичные файлы сайта или коммитить в Git. Пример названий переменных находится в `.env.example`.

Сайт будет доступен на `http://SERVER_IP:8080`.

При запуске через `start-local.bat` используются официальные тестовые ключи Cloudflare Turnstile. Для локального Docker-запуска их можно скопировать из документации Cloudflare или указать в `.env` по образцу `.env.example`. На боевом сервере обязательно замените их собственными ключами для `clipsearch.ru`.

## Заявки

Форма проверяет одноразовый токен Cloudflare Turnstile на сервере, затем отправляет заявку методом `sendMessage` в настроенный Telegram-чат. Заявка считается принятой только после успешного ответа Telegram Bot API. Локально заявки не сохраняются и по электронной почте не отправляются.

В Telegram-сообщение входят имя, телефон, почта, компания, московское время и источник заявки. Для всплывающей формы источником становится конкретная кнопка, с которой посетитель её открыл; открытая форма перед футером передаёт собственное название блока.

## Структура

- `public/index.php` — лендинг;
- `public/submit.php` — обработчик формы;
- `public/assets/` — стили, JavaScript, шрифт и изображения;
- `Dockerfile`, `docker-compose.yml` — запуск в Docker/Portainer;
- `start-local.bat` — локальный запуск Windows.
